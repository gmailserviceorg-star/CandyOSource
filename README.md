# CandyOSource
AUTHOR: gmailserviceorg-star
TEAM: sweetprogrammers

**MORE INFORMATION:**
* Candy OS is an CLI Operating system powered by it's own Bootloader : sweetboot
* This is the source code page of the Operating system.
* Kernel/ : CKernel.c
* boot/ : sweetboot.asm, MasterBR.asm, VolumeBR.asm
* etc/ : sudo.asm, ls.asm, del.asm, kill.asm,
* binaries/ : binaries.c, h10.c, h20.c, h31.c
* sectors/ : 0.asm, 1.asm, 2.asm
* cmd/ : shell.asm, shell.c, call.c
* shell/ : shell.asm, A920brsctor.asm
